{# ================= HOW IT WORKS ================= #}

How the prediction is made

Your details go into a Random Forest: 200 decision trees trained on {{ "{:,}".format(info.dataset.rows) }} past students. Each tree votes Placed or Not placed. The share of trees voting Placed is the probability. The class follows from it: a probability of {{ "%.2f"|format(info.threshold) }} or higher is Placed, anything lower is Not placed.

A second, simpler model, Logistic Regression, makes its own estimate as a cross-check. When the two models disagree, the result slip says so.

Used as inputs
CGPA, aptitude score, backlogs, internships, projects, certifications, coding, communication and soft skills, degree and branch.
Left out on purpose
Student ID, because it is only a label. Gender and age, so a prediction can never depend on them.
Trained and tested
{{ "{:,}".format(info.dataset.rows - info.dataset.test_rows) }} students for learning. {{ "{:,}".format(info.dataset.test_rows) }} were held back and used only for testing.
Class balance
{{ pct(info.dataset.placement_rate) }} of students in the data were placed, so a model that always answered "Not placed" would still be right {{ pct(1 - info.dataset.placement_rate) }} of the time. That is why we check more than accuracy.

Why does the Random Forest score about 100%?

Real placement outcomes are never perfectly predictable, so a perfect score is a warning, not a trophy. In this dataset the labels follow strict cut-offs. For example, no student with a coding skill below 5 was placed. Decision trees capture cut-offs exactly, so the forest recovers them without error. Logistic Regression assumes effects add up smoothly, which is why it lands at {{ pct(lr.accuracy) }}. Expect lower accuracy on real placement data, where interviews and hiring conditions also matter.

{# ================= RESPONSIBLE USE ================= #}

Using predictions responsibly

Support, not selection

Use a prediction to find students who could use coaching early. Never use it to rank students, limit their opportunities or decide who gets an interview.

Two kinds of mistakes

A false positive says Placed when the student was not, which can create false comfort. A false negative says Not placed when the student was, which can discourage someone. In a support setting false negatives do more harm, so a counsellor should review every Not placed result.

A probability is not a promise

A probability of 70% means that about 70 in 100 past students with similar profiles were placed. Any one student can land on either side.

Patterns, not causes

The model finds patterns in past data. It does not prove that raising one score will cause a placement, so treat the suggestions as places to focus, not guarantees.

Fairness check by gender

Gender is not an input to the model. We still compare its results across groups on the test students.
